    トリミング・拡大縮小

    正方形の表示枠を見ながら、画像をドラッグして位置を動かせます。元ファイルは変更せず、GIFの動きも残ります。「全画像の大きさを揃える」を実行すると、基準画像以外の拡大率と位置は自動で上書きされます。

    トリミングについて

    市松模様の四角からはみ出した部分が非表示になります。縮小すると、画像の周りに透明な余白を作れます。

    実寸で見る

    調整中の内容を100%で表示します（1 CSS px＝実表示の1 CSS px）。大きい場合は縦横にスクロールできます。開閉では保存・確定しません。エフェクトは右向きの発生位置です。

    JPG 背景透過

    背景を透明なPNGに変換

    素材の透過編集用プレビュー（表示サイズとは異なります）

    JPG自体には透明部分を保存できないため、背景色を取り除いたPNGをアプリ内で作ります。単色や白背景の画像に向いています。

    きれいに抜くコツ

    背景に近い色がキャラクター内にもある場合は「強さ」を少し下げてください。写真のような複雑な背景は、専用の切り抜きツールの方が適しています。
