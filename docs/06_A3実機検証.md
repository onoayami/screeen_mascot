# 06｜A3実機検証

この手順は、Release A3で残っているMac実機・依存版・標準解凍の証拠を集めるためのものです。自動検査が成功しても、未確認の項目を成功扱いにはしません。

## 大切なこと

- 検証は、配布されたソースZIPを標準機能で展開した直後のフォルダで行います。
- Macスクリプトは一時コピーだけを変更し、展開した原本を変更しません。
- `A3-Mac実機検証.command`内の`electron@latest`／`electron-builder@latest`は互換性候補の検査です。固定版の配布検証とは別扱いで、一時コピーの候補`package.json`と`package-lock.json`を原本へ自動反映しません。
- GitHub Actionsの通常macOSジョブはロックファイル固定版で検証・ビルドし、`electron@latest`候補は手動起動時だけ別ジョブで検証します。
- Apple ID、パスワード、証明書、キーチェーン、環境変数は収集しません。
- 作成された結果ZIPを確認してから、依存版と最低対応macOSを正式決定します。
- 開発用クローンでは、`v2.3.4-baseline` タグがある場合は `npm run test:automated`、タグが無い場合は `npm run test:automated:local` を使います。後者はfixture整合性検証を維持して`.git`を除いた一時コピーでテストするため、そのコピー内ではGit履歴検証を実行できません。

## Macで行うこと

### 1. 標準機能で展開する

`desktop-mascot-ui-…zip`をダブルクリックします。macOS標準の**アーカイブユーティリティ（Archive Utility）**でフォルダが作られます。

他の解凍アプリは使わず、作成されたフォルダへ入ってください。

### 2. 検証を開始する

`A3-Mac実機検証.command`をダブルクリックします。

初回にmacOSが確認を求めた場合は、ファイルを右クリックして**開く**を選びます。Node.jsがない場合は案内ページが開くため、LTS版を入れてからもう一度ダブルクリックします。

処理中は次を自動実行します。

1. 日本語説明書名、UTF-8本文、Unicode NFCを検査
2. 原本のツリーハッシュを記録
3. `/tmp`へ一時コピー
4. 一時コピーだけでElectron／electron-builderの`latest`互換性候補を完全固定（固定版の配布検証とは別）
5. 候補`package-lock.json`を作成
6. `npm ci`を実行
7. A3・A2・A1・Phase 0・既知不具合・設定検査を実行
8. 署名を自動探索せずUniversal版をビルド
9. DMG検査、成果物SHA-256、アプリのCPU構成を記録
10. 原本が変化していないことを再確認

ネットワーク速度により時間がかかります。ウィンドウを途中で閉じないでください。

### 3. 結果を共有する

デスクトップに次が作られます。

- `Desktop-Mascot-A3-Result-日時.zip`：共有する小さな結果ZIP
- `Desktop-Mascot-A3-Build-日時`：DMGなどのテスト用ビルド結果

結果ZIPにはログ、Mac情報、依存候補、lockfile候補、ハッシュを含みます。ビルド本体は大きいため結果ZIPへ入れません。

`結果を確認してください.txt`が「自動検証結果: 成功」でも、次は未確認のままです。

- 実際のマスコット表示・ドラッグ・クリック透過
- Intel Mac上での実起動
- 最低対応macOSでの実起動
- Developer ID署名、公証、Gatekeeper
- Windows標準展開

## Windowsで行うこと

### 1. 標準機能で展開する

ZIPを右クリックし、Windowsエクスプローラー標準の**すべて展開**を選びます。

### 2. 名前と本文を確認する

展開したフォルダ内の`A3-Windows解凍確認.bat`をダブルクリックします。

次を検査します。

- 6件の日本語説明書名
- Unicode NFC
- UTF-8として厳格に読めること
- 本文・ファイル名に置換文字`U+FFFD`がないこと

デスクトップの`A3-Windows解凍結果-日時.txt`を共有してください。この処理はファイル名と本文だけを読み、元ファイルを書き換えません。

## 通常の配布ビルドについて

A3検証済みの`package-lock.json`が原本へ反映されるまで、`build-mac.command`と`npm run build:mac:*`は安全停止します。未確認の`latest`依存で配布物を作らないためです。

正式なlockfileを反映した後は、`build-mac.command`が`npm ci`からUniversal版を作ります。

## 結果の判定

A3全体の完了には、少なくとも次が必要です。

- Mac結果ZIPからElectron／electron-builder／Node／npmの具体版を確定
- 候補lockfileをレビューして原本へ反映
- `npm ci`から同じ依存が再現することを再確認
- Apple SiliconとIntelの実起動
- 最低対応macOSの決定と実起動
- macOSアーカイブユーティリティとWindowsエクスプローラーで日本語名が一致

証拠がない項目はチェックせず、未完了のまま残します。
