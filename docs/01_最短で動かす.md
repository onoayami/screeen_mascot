# 01｜最短でマスコットを動かす

## 1. 必要なもの

- Mac
- VS Code
- Node.js の **LTS版**：<https://nodejs.org/>

Node.jsを入れた後、VS Codeをいったん終了して開き直してください。

## 2. プロジェクトを開く

1. ZIPをダブルクリックして展開します。
2. 展開してできたプロジェクトフォルダをデスクトップなどへ置きます。フォルダ名は配布ファイルの名前によって異なります。
3. VS Codeで **ファイル → フォルダーを開く** を選び、このフォルダを開きます。
4. VS Codeで **ターミナル → 新しいターミナル** を選びます。

## 3. 初回準備

ターミナルへ次を貼り、Enterを押します。

```bash
npm install
```

Electronと、配布用ファイルを作るelectron-builderが入ります。初回だけ数分かかる場合があります。

## 4. 召喚する

```bash
npm start
```

サンプルのくらげが現れ、Mac上部のメニューバーに **🪼** が出れば成功です。

## 5. 操作する

- キャラクターをドラッグ：好きな場所へ移動
- キャラクター以外をクリック：後ろのブラウザやアプリをそのまま操作
- 🪼 → **動きを一時停止**：自動移動を停止
- 🪼 → **画面の中央へ戻す**：見失ったときに使用
- 🪼 → **設定を開く…**：ドラッグ&ドロップで画像や動きを設定
- 🪼 → **画像・設定フォルダを開く**：高度な手動編集
- 🪼 → **設定を再読み込み**：手動編集した内容を反映
- 🪼 → **終了**：アプリを完全に終了

## 6. 次回から

```bash
npm start
```

だけで起動できます。

Mac上で `start.command` をダブルクリックする方法もあります。セキュリティ警告が出る場合は、VS Codeのターミナルから `npm start` を使ってください。

ダウンロードしたZIPを展開した後、`.command`が「開発元を検証できない」などの理由で開かない場合は、
**システム設定 → プライバシーとセキュリティ → このまま開く** を使ってください。
macOS 15以降では、右クリックの「開く」だけでは実行できない場合があります。
社内ネットワークなどでElectronのダウンロードに失敗した場合は、もう一度実行してください。
それでも失敗するときは、ネットワーク管理者に確認してください。

## うまくいかないとき

### `npm: command not found`

Node.jsが入っていないか、VS Codeが古い状態です。Node.jsのLTS版を入れ、VS Codeを再起動してください。

### 画像が出ない

🪼 → **設定を開く…** を選び、対象のアクションへ画像をもう一度ドラッグ&ドロップしてから **保存して反映** を押します。

### 終了できない

🪼 → **終了** を選びます。開発中なら、VS Codeのターミナルを選んで `Control + C` でも停止できます。
