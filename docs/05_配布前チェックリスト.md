# 05｜配布前チェックリスト

## 名前・情報

- [ ] `package.json` 上部の `productName` を変更した
- [ ] `build.productName` も同じ名前にした
- [ ] `appId` を自分専用の値にした
- [ ] `version` を正しく設定した
- [ ] `author` と `LICENSE` の名前を変更した
- [ ] `build/icon.png` を自分のアイコンへ差し替えた

## 画像・設定

- [ ] 配布可能な権利を持つ素材だけを使っている
- [ ] 設定画面で画像・動き・エフェクトを登録した
- [ ] **保存して反映** を押した
- [ ] `characters/default` に含める初期画像と設定を確認した
- [ ] `npm run check` が成功した
- [ ] 休む・歩く・飛ぶ・歌うなど、全動作を確認した
- [ ] エフェクトは必要な動作だけに設定した
- [ ] 画像の容量が大きすぎない

## 操作

- [ ] ドラッグできる
- [ ] キャラクター以外のクリックが後ろへ通る
- [ ] 🪼から停止・再開できる
- [ ] 🪼から中央へ戻せる
- [ ] 🪼から終了できる
- [ ] 設定画面を開ける
- [ ] 画像とエフェクトをドラッグ&ドロップできる
- [ ] JPGを透明PNGへ変換し、背景透過を確認できる
- [ ] 保存内容がマスコットへ反映される
- [ ] 画像・設定フォルダを開ける
- [ ] 設定の再読み込みができる

## ビルド

- [ ] Apple Silicon版・Intel版・Universal版のどれを配るか決めた
- [ ] `npm run build:mac:universal` などが成功した
- [ ] 新しいMacユーザーアカウント、または別のMacでDMGを試した
- [ ] DMGからApplicationsへコピーして起動できた

## 一般公開する場合

- [ ] Apple Developer Programへ参加した
- [ ] Developer ID Applicationで署名した
- [ ] Appleの公証を通した
- [ ] `codesign` と `spctl` の確認に成功した
- [ ] 公証チケットを確認した
- [ ] SHA-256を作成した
- [ ] 利用者向け説明書、問い合わせ先、更新内容を用意した

## 最終確認

- [ ] 配布するのは完成した `.dmg` であり、開発用ソースZIPではない
- [ ] Apple ID・パスワード・証明書などの秘密情報がファイルに入っていない
- [ ] バージョン番号とファイル名が一致している
