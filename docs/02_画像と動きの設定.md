# 02｜設定画面で画像と動きを登録する

このUI版では、基本的に `config.json` を編集する必要はありません。

## 設定画面を開く

1. アプリを起動します。
2. Mac上部の **🪼** をクリックします。
3. **設定を開く…** を選びます。

## 画面の構成

### 左上：マスコット全体

- 表示サイズ
- ドラッグした位置を記憶する

### 左下：アクション

「休む」「歩く」「飛ぶ」「歌う」など、画像と動きの組み合わせを管理します。

- ＋：新しい動作を追加
- ↑／↓：表示順を変更
- 削除：設定から動作を外す
- 選ばれやすさ：各アクションの右側にある小さな欄から、1〜10の整数で直接変更

削除しても、画像ファイル自体はすぐに消しません。

## キャラクター画像を入れる

1. 左側で設定したいアクションを選びます。
2. FinderからGIF・PNG・WebP・SVGを用意します。
3. **画像と名前** の大きな点線枠へドラッグ&ドロップします。
4. ドラッグが難しい場合は、点線枠をクリックして画像を選びます。
5. 動作名を「歩く」「眠る」などへ変更します。

画像は自動的にアプリの画像フォルダへコピーされます。
画像ファイルは20MB以下です。ラスター画像は16MP以下、SVGは幅・高さ4096以下にしてください。SVGのDOCTYPE/ENTITY宣言は使用できません。

画像を差し替えたり動作を削除したりしても、既存素材は自動削除しません。不要になった素材は、画像・設定フォルダから手動で整理してください。JPGをドロップしたあと変換をキャンセルした場合や、透明PNGへの変換に成功して元JPGが未使用の場合は、そのセッションで新規コピーしたJPGだけを削除します。

### プレビューの「実寸」と「縮小表示」

- 画像欄・トリミング画面・サイズ比較カード・エフェクト配置は、収まる場合は **実寸 100%**、収まらない場合だけ縮小し、表示率を示します。たとえば128pxは128 CSS px、600pxを300pxの領域で見る場合は **縮小表示 50%** です。左の一覧は小さなサムネイルのままです。
- 画像登録後の画像欄は表示枠に合わせて小さくなりますが、同じ欄へドロップまたはクリックして画像を差し替えられます。画像未登録時は選びやすい大きさのドロップ欄を表示します。
- **実寸で見る** は別の確認画面を開き、常に1 CSS px＝実表示の1 CSS pxで表示します。大きい画像や枠外のエフェクトは縦横にスクロールできます。透明な余白・トリミング・倍率・位置・左右反転も反映されます。
- 保存前の設定や、トリミング・サイズ比較画面で調整中の内容も確認できます。確認画面を開閉しても保存・確定されず、元の編集画面でキャンセルすれば調整は破棄されます。
- 表示枠は設定画面のある画面の作業領域を基準とし、端の12pxの安全余白を除いて収めます。設定サイズが大きすぎる場合は設定値と実効サイズを併記します。別の画面へマスコットを移した場合、画面の大きさにより実効サイズは異なります。ここでいう実寸は物理的な長さではなくCSS pxです。
- トリミング画面の **編集用に拡大する** は、小さい画像をドラッグしやすくするための表示専用です。「編集用拡大」と明示され、設定倍率や「実寸で見る」には影響しません。
- エフェクト素材欄とJPG透過画面は素材確認・編集用で、実表示の大きさではありません。

### トリミング・拡大縮小

画像を登録した後、**トリミング・拡大縮小** を押すと専用画面が開きます。

- 拡大・縮小：画像の表示倍率を調整
- 左右の位置：画像を左右へ移動
- 上下の位置：画像を上下へ移動
- 市松模様の正方形からはみ出す部分：表示時にトリミング

元画像は変更しない非破壊方式です。GIFを調整してもアニメーションは残ります。

![トリミング・拡大縮小画面](image-editor-screen.png)

### 全画像の見た目の大きさを揃える

左側の **全画像の大きさを揃える** を押すと、登録した画像が同じ枠で一覧表示されます。

1. 基準にする画像を選び、**基準画像に自動で揃える** を押すと、基準画像以外の大きさと位置が自動で揃います。
2. 必要なら各カードで表示倍率を調整したり、画像をドラッグして位置を直します。
3. **保存して反映** を押します。

「表示する大きさ」はマスコット全体のpxサイズです。画面の高さの割合と図で、画面上の大きさを確認できます。
「大きさを揃える」は枠に対する画像の見た目の割合です。「この大きさに揃える」で全画像を整え、カードごとに微調整できます。上限は92%で、枠に余白を残します。
サイズや画像の調整は、**保存して反映** を押すと保存され、マスコットに反映されます。
追従エフェクトも同じ比率で調整できます。画面に収まらないサイズは、表示時に最大サイズへ縮小されます。

![全画像のサイズ調整画面](size-manager-screen.png)

### 画像の見切れ

- 画像が正方形の枠からはみ出すと、その部分は実際の表示でも見えません。
- STEP 1 の状態表示と動作一覧の「⚠」で、画像が枠からはみ出している場合に警告を確認できます。
- 「枠に収める」は、はみ出した画像を補正し、見た目の大きい辺を最大92%にして余白を作ります。トリミング画面では警告のみで、操作は止まりません。
- サイズ比較画面の「見切れを直す」は、枠からはみ出した画像だけを枠内へ補正します。変更は「保存して反映」で確定します。

### クリック範囲と画像の見切れ

- マスコットは正方形の枠全体がクリック対象です。透明部分も枠内なら、後ろのアプリをクリックできません。
- 拡大した画像が枠からはみ出した部分は表示されず、枠で切り取られます。

### JPGの背景を透明にする

JPGには透明部分を保存する仕組みがありません。そのため、JPGを入れると専用画面が開き、背景を取り除いた透明PNGへ変換します。

1. JPGを画像欄へドラッグ&ドロップします。
2. 四隅から背景色が自動判定されます。
3. 必要なら **消したい背景色** を選び直します。
4. **背景を消す強さ** と **境界のなめらかさ** を調整します。
5. 市松模様のプレビューで透明部分を確認します。
6. **透明PNGに変換** を押します。

![JPGの背景透過画面](jpg-transparency-screen.png)

白や単色背景の画像に向いています。背景に近い色がキャラクター内にもある場合は「強さ」を下げます。写真のように複雑な背景は、専用の背景切り抜きツールを使ってからPNGで保存する方がきれいです。

## 動き方を選ぶ

| 画面の選択肢 | 動き |
|---|---|
| その場に留まる | 休む・眠る・歌う向け |
| 画面下部を左右に歩く | 歩く・走る向け |
| 画面内を自由に動く | 飛ぶ・漂う向け |
| 画面上から降ってくる | 雨・雪・落下するキャラクター向け |
| 画面下から発射される | ロケット・花火・飛び出す演出向け |
| 画面を縦横に動く | 水平・垂直方向へ直角に動く演出向け |

速さは0〜300px/秒で設定できます。速さを変更すると、動き方の上にある **速度プレビュー** で画像が左右に動きます。**止める** を押すといつでも停止でき、もう一度速さを変更すると再生します。このプレビューは速さの目安を示すための横移動で、選択中の移動方法そのものを再現するものではありません。GIFのアニメーションと画像の左右反転設定はプレビューにも反映されます。

## 表示される頻度と時間

- **選ばれやすさ**：1〜10の整数を入力します。これは抽選1回ごとの重みで、長期の選択回数は、たとえば2なら1の約2倍です。同じ動作が連続することがあります。表示時間の比は「最短時間・最長時間」で別に決まります。左側のアクション一覧からも変更できます。
- **最短時間・最長時間**：その動作が続く時間です。
- 「表示時間・速さを一括設定」では、表示時間と速さを別々に選んで設定できます。表示時間は初期状態で選択され、全動作に適用されます。速さは誤って一括変更しないよう初期状態では選択されず、選択すると「その場に留まる」以外の動作だけに適用されます。設定後は「保存して反映」で保存します。
- 旧版で保存した速さが301〜2000の場合、設定画面では上限300として読み込み、警告と未保存状態を表示します。元の設定ファイルは読み込み時に変更せず、全体保存または選択中の動作の保存時に旧速さを300で更新します。選択中の動作だけを保存する場合も、厳密な保存範囲に旧速さの修正を含める必要があるため、他の動作の旧速さも300になります。
- **反転設定**：次の3種類から選びます。
  - 向きに合わせて反転する：左へ進むときに左右反転
  - 向きに合わせて反転しない：元画像の向きを維持
  - 自由に反転する：動作が選ばれるたび、向きをランダムに決定
- 画像は右向きを「前」として扱います。左向きの絵は「画像を左右反転する」をONにして、右向きにそろえます。
- 「向きに合わせて反転する」では、左へ進むとき画像が反転し、進行方向を向きます。
- 追従エフェクトの横位置は、画像が反転すると左右が反対になります。エフェクト画像そのものは反転しません。
- 追従エフェクトの横位置は、基本の左右反転設定では変わりません。

## 足跡などの追従エフェクト

設定欄にはキャラクターとエフェクトの **リアルタイムプレビュー** が表示されます。横位置・縦位置・大きさを入力すると、音符や足跡がどこへ出るかすぐ確認できます。

![追従エフェクトのリアルタイムプレビュー](effect-live-preview-screen.png)

プレビューには、エフェクトが**実際に出現する瞬間の位置**を静止表示します。実画面のように上へ消えるアニメーションを付けないため、音符の位置を入力中に正確に比較できます。プレビューと実表示はどちらもエフェクト画像の中心を基準にしており、正方形ではない画像でも同じ位置になります。

キャラクターとエフェクト全体が収まるよう、同じ比率でのみ縮小します。画像の縦横比は維持されます。「実寸で見る」では入力中の幅・横位置・縦位置を100%で確認できます。マスコットが画面サイズの上限で縮む場合でも、エフェクトの幅や位置は実表示と同じく独立したpx値です。

1. **追従エフェクト → 使う** をONにします。
2. 足跡・光・音符などの画像を点線枠へドラッグ&ドロップします。
3. 次を調整します。

- 間隔：何秒ごとに出すか
- 大きさ：画像の表示幅
- 消えるまで：表示時間
- 横位置：0から＋で右、−で左へ移動
- 縦位置：0から＋で上、−で下へ移動
- 停止中も表示：歌の音符など、動かない時にも出す場合にON

エフェクトをONにしたアクションだけに表示されます。たとえば「歩く」だけ足跡を付け、「休む」「飛ぶ」には何も付けない設定ができます。

初期設定のクラゲには、猫の肉球ではなくシンプルな横長楕円の移動跡が入っています。以前の初期肉球画像をそのまま使っている場合は、更新時に楕円へ自動で置き換わります。自分で追加したエフェクト画像は変更されません。

初期クラゲ本体も、波打つ傘、長さと曲がり方の異なる7本の触手、複数の光と縁取りを使ったデザインです。「休む・歩く・飛ぶ・歌う」ごとに表情と色合いも変わります。旧版の初期クラゲ画像だけを使っている場合は自動更新されますが、自分で追加または編集した画像は上書きされません。

## 保存する

選択中の動作だけを先に保存する場合は、動作名の右にある **保存** を押します。画像、名前、頻度、表示時間、動き方、反転、エフェクトなど、その動作の設定だけが保存されます。全体設定や別の動作の編集内容は一緒に保存されません。

画面上部または右下の **保存して反映** は同じ全体保存で、全体設定と動作一覧を含むすべての変更を保存します。動作の並べ替えや削除も、この全体保存で確定します。動作編集欄の **保存** は選択中の動作だけを保存します。新しい動作を個別に保存した場合は、その動作だけが一覧へ追加されます。追加位置は、編集中の一覧で直前にある保存済み動作の後です（直前に保存済み動作がなければ先頭に追加します）。

保存した内容をマスコットへ反映できたことを確認すると完了です。反映を確認できなかった場合は成功表示にせず、理由と再試行メッセージが表示されます。

保存前の変更を取り消す場合は **変更を破棄** を押します。`Command + S` でも保存できます。

## 使える画像

- 透過GIF：アニメーション向き
- 透過PNG：静止画向き
- WebP：容量を小さくしやすい
- SVG：拡大してもきれい
- JPG：背景透過画面から透明PNGへ変換して使用

キャラクター画像は1辺300〜800px程度、1ファイル数MB以内が扱いやすい目安です。画像内の透明な余白が大きいと、つかめる範囲も大きくなります。

## マスコットが画面外へ出ない仕組み

- すべての動きで、マスコット全体を画面端から12px内側に保ちます。
- 保存されていた位置が現在の画面外でも、起動時に自動で画面内へ戻します。
- モニターの取り外し、解像度変更、Dock位置の変更後も自動で現在の表示領域に合わせます。
- macOSの別の操作スペースやフルスクリーン画面でも表示を維持します。
- 見失った場合は、メニューバーの **🪼 → 画面の中央へ戻す** を押すと、カーソルがある画面の中央へ呼び戻せます。

## 高度な設定

必要な場合だけ、🪼 → **画像・設定フォルダを開く** から `config.json` を直接編集できます。編集後は🪼 → **設定を再読み込み** を選びます。
