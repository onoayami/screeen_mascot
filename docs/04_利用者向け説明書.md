# Desktop Mascot v1 利用者向け説明書

## インストール

1. 配布された `.dmg` をダブルクリックします。
2. 表示されたアプリを `Applications` フォルダへドラッグします。
3. `アプリケーション` フォルダからアプリを起動します。

ダウンロード元を確認したうえでmacOSが起動を止めた場合は、**システム設定 → プライバシーとセキュリティ → このまま開く** を選んでください。

## 基本操作

- キャラクターをドラッグ：位置を移動
- キャラクター以外をクリック：後ろのアプリを操作
- Mac上部の🪼：操作メニューを開く

🪼メニュー：

- **マスコットを隠す／表示**
- **動きを一時停止／再開**
- **画面の中央へ戻す**
- **設定を開く…**
- **画像・設定フォルダを開く**
- **設定を再読み込み**
- **終了**

## 自分の画像へ変更する

1. 🪼 → **設定を開く…** を選びます。
2. 左側でアクションを選ぶか、＋で追加します。
3. 既存の動作をもとに作る場合は、**複製** を押します。キャラクター画像と追従エフェクト画像も独立したファイルとしてコピーされ、複製した動作は元のすぐ下に追加されます。
4. キャラクター画像を点線枠へドラッグ&ドロップします。
5. 動き方と速さを選びます。
6. 必要なら追従エフェクトをONにし、足跡などの画像をドロップします。
7. **保存して反映** を押します。

画像欄をクリックしてFinderから選ぶこともできます。通常はJSONを編集する必要はありません。

設定画面の **ログイン時に自動起動** をオンにすると、次回のログイン時から起動します。反映されない場合やmacOSの許可が必要な場合は、**システム設定 → 一般 → ログイン項目** でアプリを追加または許可してください。

JPGを選ぶと、背景を透明なPNGへ変換する画面が開きます。背景色と強さを調整し、プレビューを確認して **透明PNGに変換** を押してください。白や単色背景の画像に適しています。

## 配布版を作る

設定画面の下にある **配布版作成** を押すと、現在の設定と使用中の画像を含むアプリのZIPを作成できます。ZIPを受け取った人は解凍し、中のアプリを **アプリケーション** フォルダへ移動して起動します。追加のプログラムや設定作業は必要ありません。

配布版の設定と画像は、元のアプリや別の配布版とは別に保存されます。配布する画像を使う権利があることを確認してください。

## 終了

🪼 → **終了** を選びます。ウィンドウを隠すだけでは終了していません。

## アンインストール

1. 🪼 → **終了** を選びます。
2. `アプリケーション` フォルダ内のアプリをゴミ箱へ移動します。
3. 自分で入れた画像・設定も消す場合は、Finderで `移動 → フォルダへ移動` を選び、次を開いてアプリのフォルダを削除します。

```text
~/Library/Application Support/Desktop Mascot/
```

アプリ名が変わっても、既存の設定と画像はこの `Desktop Mascot` フォルダに保存されています。

## プライバシー

このスターターキットの標準版は、画像と設定をMac内で処理し、インターネットへ送信しません。配布者が機能を追加した場合は、配布者の説明を確認してください。
