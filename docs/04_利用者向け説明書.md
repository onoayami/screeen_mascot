# Desktop Mascot 利用者向け説明書

## インストール

1. 配布された `.dmg` をダブルクリックします。
2. 表示されたアプリを `Applications` フォルダへドラッグします。
3. `アプリケーション` フォルダからアプリを起動します。

ダウンロード元を確認したうえでmacOSが起動を止めた場合は、**システム設定 → プライバシーとセキュリティ → このまま開く** を選んでください。

## 基本操作

- キャラクターをドラッグ：位置を移動
- キャラクター以外をクリック：後ろのアプリを操作
- Mac上部の🪼：操作メニューを開く

🪼メニュー：

- **マスコットを隠す／表示**
- **動きを一時停止／再開**
- **画面の中央へ戻す**
- **設定を開く…**
- **画像・設定フォルダを開く**
- **設定を再読み込み**
- **終了**

## 自分の画像へ変更する

1. 🪼 → **設定を開く…** を選びます。
2. 左側でアクションを選ぶか、＋で追加します。
3. キャラクター画像を点線枠へドラッグ&ドロップします。
4. 動き方と速さを選びます。
5. 必要なら追従エフェクトをONにし、足跡などの画像をドロップします。
6. **保存して反映** を押します。

画像欄をクリックしてFinderから選ぶこともできます。通常はJSONを編集する必要はありません。

JPGを選ぶと、背景を透明なPNGへ変換する画面が開きます。背景色と強さを調整し、プレビューを確認して **透明PNGに変換** を押してください。白や単色背景の画像に適しています。

## 終了

🪼 → **終了** を選びます。ウィンドウを隠すだけでは終了していません。

## アンインストール

1. 🪼 → **終了** を選びます。
2. `アプリケーション` フォルダ内のアプリをゴミ箱へ移動します。
3. 自分で入れた画像・設定も消す場合は、Finderで `移動 → フォルダへ移動` を選び、次を開いてアプリのフォルダを削除します。

```text
~/Library/Application Support/Desktop Mascot/
```

アプリ名を変更した版では、最後のフォルダ名もそのアプリ名になります。

## プライバシー

このスターターキットの標準版は、画像と設定をMac内で処理し、インターネットへ送信しません。配布者が機能を追加した場合は、配布者の説明を確認してください。
