# Desktop Mascot UI版

好きなGIF・PNG・WebP・SVG・JPGを使い、Macの画面上を動き回るマスコットを作るElectronプロジェクトです。**プログラムやJSONを編集しなくても、設定画面から画像と動きを登録できます。** JPGはアプリ内で背景を取り除き、透明PNGへ変換できます。

## UI版でできること

- マスコット全体を画面端から12px内側に保ち、画面外への迷子を防止
- モニターの着脱・解像度変更・macOSの操作スペース切り替え後も自動復帰
- 🪼メニューの「画面の中央へ戻す」で、カーソルがある画面へいつでも呼び戻し
- キャラクター画像をドラッグ&ドロップ
- JPGの背景色を自動判定し、透明PNGへ変換
- 背景を消す強さ・境界のなめらかさをプレビューしながら調整
- 休む・歩く・飛ぶ・歌うなどの動作を追加・削除・並べ替え
- 登録画像を非破壊でトリミング・拡大・縮小・位置調整（GIFの動きも保持）
- 「その場」「左右移動」「自由移動」「上から落下」「下から発射」「縦横移動」を選択
- 速さ（0〜300）、表示時間、選ばれやすさを画面から調整（1〜10の整数・数字が大きいほど長期の選択回数が増える。同じ動作が連続する場合あり）
- 速さ変更時に左右移動で目安をプレビューし、ボタンで停止
- 表示時間・速さを個別に選んで一括設定（速さは移動する動作だけが対象）し、そのまま保存して反映
- 左向き画像を左右反転して右向きにそろえ、左へ進むときは追従エフェクトの横位置も反転
- 足跡・光・音符などの追従画像もドラッグ&ドロップ
- 初期クラゲの移動跡はシンプルな横長楕円（旧版の猫の肉球は自動置換）
- 初期クラゲは、波打つ傘・7本の有機的な触手・重なったハイライトへリデザイン
- 「休む・歩く・飛ぶ・歌う」ごとに表情と色合いを変え、仮の図形らしさを軽減
- 追従エフェクトの大きさと位置をキャラクター上でリアルタイムプレビュー
- プレビューと実表示で同じ「画像の中心」を使い、音符の発生位置を完全一致
- 位置確認中のプレビューは静止し、消えるアニメーションによる見かけのずれを防止
- 横位置は＋で右、縦位置は＋で上へ移動
- 全アクション画像を並べ、選んだ基準画像の見た目の大きさへ自動調整
- 画像が枠からはみ出した場合に警告・補正し、余白を確保
- マスコットの表示する大きさを画面の図で確認し、92%以内で画像の大きさを揃える
- 追従エフェクトも、マスコットと同じ比率で調整
- エフェクトの大きさ・間隔・位置・消える時間を調整
- 動作名の横の「保存」で選択中の動作だけを保存（全体設定や別の動作の未保存内容は含みません）
- 動作一覧の並べ替え・削除は、下部の「保存して反映」で確定
- 「保存して反映」で、選択中の動作をマスコットへ即表示
- マスコット側の画像読み込みと反映完了を確認してから「保存済み」と表示
- 反映に失敗した場合は成功表示にせず、理由と再試行を案内
- 「配布版へ反映」で、現在の画像と設定をビルド用の初期状態へコピー
- キャラクター以外のクリックは後ろのアプリへ通す
- Mac上部の🪼から停止・再開・設定・終了

旧版の初期クラゲ画像をそのまま使っている場合は更新時に新デザインへ自動で切り替わります。自分で追加・編集した画像は上書きしません。

## 最短手順

```bash
npm install
npm start
```

起動後、Mac上部の **🪼 →「設定を開く…」** を選びます。

1. 左側のアクションを選ぶ、または＋で追加
2. 画像欄へGIFやPNGをドラッグ&ドロップ
3. 必要なら **トリミング・拡大縮小** で画像を調整
4. 選ばれやすさ（1〜10の整数）・動き方・速さ・反転設定を選ぶ
5. 必要なら追従エフェクトをONにして画像をドロップ
6. 選択中の動作だけを保存する場合は、動作名の横の **保存**
7. 全体設定や一覧の並べ替え・削除も確定する場合は、下部の **保存して反映**

速さは0〜300px/秒です。速さ変更時の速度プレビューは左右移動による目安で、実際の移動方法とは異なります。旧版の速さ301〜2000は上限300として警告付きで読み込みますが、元の設定ファイルは自動変更しません。保存時に旧速さを300へ更新し、選択中の動作だけを保存する場合も旧速さの修正は全動作に適用されます。

JPGを選ぶと背景透過画面が開きます。四隅から背景色を自動判定し、プレビューを見ながら調整して **透明PNGに変換** を押します。JPG形式自体は透明部分を保存できないため、アプリ内ではPNGとして保存されます。

## 配布用アプリを作る

現在のA3チェックポイントでは、未確認の`latest`依存で配布物を作らないよう安全停止します。まず、配布されたソースZIPをmacOS標準機能で展開し、`A3-Mac実機検証.command`をダブルクリックしてください。詳しくは`docs/06_A3実機検証.md`にあります。

検証結果から正式な`package-lock.json`を反映した後は、設定画面で **配布版へ反映** を押し、`build-mac.command`をダブルクリックします。内部では`npm ci`からUniversal版を作成します。

完成したDMGは`dist`フォルダに出ます。A3実機検証が完了するまでは利用者向け最終配布版として公開しないでください。

## 高度な設定

設定画面で作成した内容は `config.json` に保存されます。通常は直接編集する必要はありません。細かな調整をしたい場合だけ、🪼 →「画像・設定フォルダを開く」から編集できます。

## 開発用テスト

- `v2.3.4-baseline` タグを含むGitクローンでは `npm run test:automated` を実行します。
- タグが無い作業ツリーでは `npm run test:automated:local` を実行します。Git照合用の基準・テストは変更せず、一時コピーで全テストを実行します。

## 注意

- 配布してよい権利を持つ画像・GIFだけを使ってください。
- 一般公開で警告なく起動してもらうには、Apple Developer Program、Developer ID署名、Appleの公証が必要です。
- Apple ID、パスワード、証明書などの秘密情報はソースやGitHubへ書かないでください。
