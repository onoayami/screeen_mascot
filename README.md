# Desktop Mascot v1

好きな画像と動きを設定して、Macの画面上でマスコットを動かせるアプリです。

## インストール

macOS 13以降のApple Silicon／Intel Macに対応するUniversal版です。

[ダウンロードページ](https://github.com/onoayami/screeen_mascot/releases/latest)

リリースのAssetsから **`Desktop.Mascot-v1.dmg`** をダウンロードし、開いたウィンドウの **Desktop Mascot.app** を **アプリケーション** フォルダへドラッグします。コピー後、アプリケーションフォルダから起動してください。

ダウンロード元を確認したうえで、macOSが起動を止めた場合は、**システム設定 → プライバシーとセキュリティ → このまま開く** を選んでください。

## 使い方

1. 画面上部の 🪼 メニューから **設定を開く…** を選びます。
2. 動作を選び、画像欄へ画像を追加します。
3. **複製** を押すと、選択中の動作を画像ファイルごとコピーしてすぐ下に追加できます。
4. 必要に応じて画像や動きを調整し、**保存して反映** を押します。
4. 終了するときは 🪼 メニューから **終了** を選びます。

設定画面の **ログイン時に自動起動** をオンにすると、次回のログイン時から起動します。反映されない場合は、Macの **システム設定 → 一般 → ログイン項目** で追加または許可してください。

マスコットを見失ったときは、🪼 メニューの **画面の中央へ戻す** を選んでください。

## 配布版を作る

設定画面の下にある **配布版作成** を押すと、現在の設定と使用中の画像を含むアプリのZIPを作成できます。ZIPを受け取った人は解凍し、中のアプリを **アプリケーション** フォルダへ移動して起動します。追加のプログラムや設定作業は必要ありません。

配布版の設定と画像は、元のアプリや別の配布版とは別に保存されます。配布する画像を使う権利があることを確認してください。
