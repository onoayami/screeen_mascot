# Desktop Mascot v2.3.4

好きな画像と動きを設定して、Macの画面上でマスコットを動かせるアプリです。プログラムやJSONの編集は必要ありません。

- GIF・PNG・WebP・SVG・JPGを登録。JPGは背景を透明にできます。
- 休む・歩く・飛ぶ・歌うなどの動作や移動方法を設定できます。
- 画像のトリミング、表示サイズ、動きの速さを画面から調整できます。
- 画面端で迷子になりにくく、メニューからいつでも画面中央へ戻せます。
- 足跡や音符などの追従エフェクトを追加できます。

## かんたん導入（Mac）

### 1. DMGをダウンロード

**v2.3.4は試用版（プレリリース）です。** 安定版ではなく、Developer ID署名・公証はありません。Appleによる公証やmacOS実機での動作検証が未完了のため、警告が表示されることがあります。ダウンロードは次の公式GitHubリリースページからのみ行ってください。

[Desktop Mascot v2.3.4 のダウンロード（GitHub Releases）](https://github.com/onoayami/screeen_mascot/releases/tag/v2.3.4)

Assetsから **`Desktop.Mascot-2.3.4-universal.dmg`** をダウンロードします。`universal`版にはIntel Mac用とApple Silicon用の両方の実行形式が含まれています。対応OSの設定はmacOS 13以降です。これは対応形式と最小OSバージョンを示すもので、各Macでの動作認証を意味しません。

### 2. アプリをインストール

ダウンロードしたDMGをダブルクリックし、開いたウィンドウの **Desktop Mascot.app** を **アプリケーション** フォルダへドラッグします。コピー後、アプリケーションフォルダからDesktop Mascotを起動してください。

### 3. macOSの警告が出たとき

未署名・未公証のため、macOSがアプリを開けないという警告を表示する場合があります。**公式GitHubリリースからダウンロードしたことを確認できた場合に限り**、一度起動を試した後、**システム設定 → プライバシーとセキュリティ → このまま開く** を選んでください。表示される確認画面でも、アプリを開く操作を選びます。

出所を確認できないファイルではこの操作をしないでください。`sudo`コマンド、隔離属性の削除、その他のセキュリティ機能を無効にする操作は必要ありません。

### 4. マスコットを設定

1. 画面上部の 🪼 メニューから **設定を開く…** を選びます。
2. 左側の動作を選び、画像欄へ画像をドラッグ＆ドロップします。
3. 必要に応じて動き方、速さ、表示時間などを調整します。
4. **保存して反映** を押し、マスコット側に反映されたことを確認します。

アプリを終了するときは、画面上部の 🪼 メニューから **終了** を選びます。マスコットを見失ったときは、同じメニューの **画面の中央へ戻す** で呼び戻せます。

## よくある質問

**マスコットを見失いました。**

🪼 メニューの **画面の中央へ戻す** を選んでください。モニターの着脱や解像度変更後も、画面内へ戻す処理があります。

**JPGの背景を透明にできますか？**

JPGを設定画面へ入れると背景透過画面が開きます。背景色や境界を調整し、**透明PNGに変換** を押してください。透明部分を保存するため、アプリ内ではPNGになります。

**Intel MacとApple Silicon Macの両方で使えますか？**

DMGには両方のCPU向けの実行形式が含まれています。最低OSバージョンはmacOS 13です。ただし、Intel／Apple Siliconそれぞれの実機での動作検証は未完了です。Windows版はこのリリースに含まれません。

**安定版ですか？**

いいえ。v2.3.4は試用版（プレリリース）です。署名・公証とA3実機検証が完了した安定版ではありません。

## 詳しい機能

- 休む・歩く・飛ぶ・歌うなどの動作を追加、削除、並べ替えできます。
- 「その場」「左右移動」「自由移動」「上から落下」「下から発射」「縦横移動」を選べます。
- 速さ（0〜300px/秒）、表示時間、選ばれやすさを設定できます。表示時間と速さは個別に一括設定でき、速さは移動する動作が対象です。
- 速さの変更時に左右移動の目安をプレビューし、ボタンで停止できます。
- 画像を非破壊でトリミング・拡大・縮小・位置調整できます。GIFの動きも保持します。
- 追従エフェクトの大きさ・間隔・位置・表示時間を調整し、キャラクター上で位置をプレビューできます。
- 全アクション画像の大きさを基準画像に合わせられます。画像が枠からはみ出す場合は警告・補正します。
- 選択中の動作だけを **保存** できます。動作一覧の並べ替え・削除や全体設定は **保存して反映** で確定します。
- 画面端での移動、モニター変更後の復帰、クリック透過に対応しています。

## 開発者・ソースから起動する場合

GitHub ReleasesのAssetsにある **`Desktop.Mascot-2.3.4-universal.zip`** は、アプリと説明書類を含むZIP版です。通常はDMGからの導入が簡単です。このZIPにはREADME、START_HERE、説明書、ライセンス情報も含まれます。ソースから起動する場合は、GitHub上のソースコードを取得してください。

Node.jsのLTS版を用意し、ソースフォルダで次を実行します。

```bash
npm install
npm start
```

画像を登録した後、🪼 メニューの **設定を開く…** を選びます。設定画面で、選択中の動作だけを保存する場合は動作名の横の **保存**、全体設定や動作一覧も確定する場合は **保存して反映** を押してください。

開発用の確認コマンド：

```bash
npm run check
```

自動テストは236件成功、失敗0件、スキップ1件、TODO 2件です。開発ツリー全体のテスト方法は、Gitタグの有無に応じて以下を使い分けます。

- `v2.3.4-baseline` タグを含むGitクローン：`npm run test:automated`
- タグがない作業ツリー：`npm run test:automated:local`
