## Phase 0で確認対象にした項目

### T04 — 小さい画面と大きいマスコット

- [ ] 800×600相当または最小表示領域で1000px設定を読み込む
- [ ] 画像全体が保証範囲内で12px内側に見える
- [ ] 解像度変更、縦画面、Dock拡大後も復帰する

### T09 — 配布データの失敗安全性

- [ ] コピー先権限拒否
- [ ] 空き容量不足
- [ ] コピー途中の強制終了
- [ ] 次回起動時のstaging／backup復旧
- [ ] 旧defaultの設定・画像SHA-256が不変

### T13 — 保存状態と反映状態

- [ ] 設定画面を開いただけでは「反映済み」にならない
- [ ] 画像読込失敗時に「反映済み」にならない
- [ ] 非表示中の読込確認と、再表示後の表示確認を区別できる

### T15 — クリック透過

- [ ] カーソルを止めたままマスコットが下へ入る
- [ ] カーソルを止めたままマスコットが外へ出る
- [ ] 隠す→表示後に背後操作を妨げない
- [ ] ドラッグ終了・フォーカス喪失後に透過状態が復帰する
